# Testowanie projektu

W tej wersji projekt ma scenariusze testow recznych. Nie ma osobnego pliku `service.test.js`, poniewaz backend jest napisany w Java Spring Boot, a frontend korzysta z czystego JavaScript.

## Scenariusze do sprawdzenia

1. Rejestracja nowego klienta.
2. Logowanie klienta przez email i haslo.
3. Logowanie instruktora i administratora kontami demo.
4. Edycja profilu klienta: imie, email, metoda platnosci, haslo.
5. Rezerwacja zajec przez klienta.
6. Anulowanie rezerwacji.
7. Zakup karnetu.
8. Dodanie opinii po zakonczonych zajeciach.
9. Oznaczenie obecnosci przez instruktora.
10. Dodanie wydarzenia specjalnego przez administratora.
