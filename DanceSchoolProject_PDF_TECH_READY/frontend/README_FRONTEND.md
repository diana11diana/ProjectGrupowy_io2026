# Frontend - czesc Mariany

W tej czesci znajduje sie interfejs aplikacji. Chcialysmy, zeby uzytkownik od razu widzial trzy role systemu:

- klient,
- instruktor,
- administrator.

Najwazniejsze pliki:

- `public/index.html` - strona startowa,
- `public/client.html` - panel klienta,
- `public/trainer.html` - panel instruktora,
- `public/admin.html` - panel administratora,
- `public/assets/app.css` - wyglad aplikacji,
- `public/assets/*.js` - obsluga formularzy i pobieranie danych z API.

Interfejs jest responsywny, czyli dziala na komputerze i telefonie.
